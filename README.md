# CSP Nonce Example

A minimal Node.js HTTP server that serves a static HTML page with a fresh Content Security Policy (CSP) nonce for each HTML response.

## Requirements

Node.js 24 or later

## Usage

```bash
git clone https://github.com/jeszy75/csp-nonce-example.git
cd csp-nonce-example
npm start
```

Open <http://localhost:8080> in your browser.
